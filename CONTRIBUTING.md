# Contributing to CampusNotes

## Getting Started

1. Fork the CampusNotes repository.

2. Clone your fork using:
   git clone https://github.com/YOUR_USERNAME/vcs-campusnotes-2581411.git

3. Create a feature branch using:
   git switch -c feature/short-description

## Commit Message Guidelines

Use the Conventional Commits format:

- feat: for new features
- fix: for bug fixes
- docs: for documentation changes
- refactor: for code improvements
- chore: for maintenance tasks

Example:
git commit -m "docs: update contribution guidelines"

## Submitting Changes

1. Stage your changes using git add.
2. Commit changes with a descriptive message.
3. Push your feature branch to GitHub.
4. Open a pull request with a clear description.
5. Address reviewer comments before merging.
